# MarkView

> 🌐 **바로 쓰기**: <https://sh11025.github.io/MarkView/>
> 💾 **USB용 파일 내려받기**: [MarkView-USB.zip](https://sh11025.github.io/MarkView/MarkView-USB.zip) (약 4MB, 압축을 풀고 `MarkView.html`을 더블클릭)

**설치도, 회원가입도, 인터넷도 필요 없는 마크다운 글쓰기 도구입니다.**
브라우저에서 바로 쓰고, 쓰는 즉시 오른쪽에 완성된 모양을 보여 주며, 글은 자동으로 저장됩니다.

- 마크다운을 몰라도 됩니다. 빈 줄에서 `/` 를 누르면 제목·표·수식·그림을 **설명을 보면서 골라 넣을 수 있습니다.**
- 인터넷이 끊겨도 됩니다. 한 번 열어 두면 비행기 안에서도 쓸 수 있습니다.
- USB에 넣어 가져다니며 쓸 수 있습니다. 파일 하나를 더블클릭하면 끝입니다.
- 내 글은 **내 컴퓨터 안에만** 있습니다. 어떤 서버에도 보내지 않습니다.

> 이 문서의 "내 글" 보관 방법과 "백업" 부분(아래 6번)은 꼭 한 번 읽어 주세요. 글을 잃어버리지 않는 데 가장 중요합니다.

## 1. 어떻게 쓰나요? (3가지 방법)

| 방법 | 이럴 때 | 준비물 |
| --- | --- | --- |
| **① 웹 주소로 열기** | 가장 편한 방법. 어디서든 주소만 열면 됩니다 | 인터넷(처음 한 번만) |
| **② USB·내려받은 파일로 열기** | 인터넷이 없거나, USB에 넣어 다니고 싶을 때 | `MarkView.html` 파일 1개 |
| **③ 앱처럼 설치하기** | 바탕화면·시작 메뉴에서 바로 열고 싶을 때 | ①에서 설치 |

### ① 웹 주소로 열기

1. <https://sh11025.github.io/MarkView/> 를 **Chrome 또는 Edge**로 엽니다.
2. 끝입니다. 바로 쓸 수 있습니다.
3. 한 번 열어 두면, 이후 인터넷이 끊겨도 같은 주소로 열 수 있습니다.

### ② USB·내려받은 파일로 열기

1. [MarkView-USB.zip](https://sh11025.github.io/MarkView/MarkView-USB.zip) 을 내려받아 압축을 풀고, `MarkView.html` 을 USB나 컴퓨터에 둡니다. (자세한 내용은 [9번](#9-usb로-가지고-다니기))
2. **파일을 더블클릭**합니다. 브라우저가 열리면서 MarkView가 나타납니다.
3. 브라우저가 Chrome이나 Edge가 아니라면, 파일을 오른쪽 클릭 → **연결 프로그램** → Chrome 또는 Edge를 고르세요.

### ③ 앱처럼 설치하기

웹 주소(①)로 열었을 때 Chrome·Edge의 주소창 오른쪽에 **설치** 아이콘이 나타납니다.
화면 위쪽의 **설치** 버튼을 눌러도 됩니다. 설치하면 독립된 창으로 열리고, 인터넷이 없어도 열립니다.
(자세한 내용은 [10번](#10-인터넷-없이-쓰기와-앱으로-설치))

## 2. 처음 5분: 글 하나 써 보기

**① 새 글 만들기**
위쪽의 **새 문서** 버튼을 누릅니다. 새 탭이 열립니다.

**② 제목 쓰기**
빈 줄에서 `/` 를 누르면 메뉴가 나타납니다. **큰 제목**을 고르고 제목을 입력해 보세요.
(`/` 를 누르기 어렵다면 도구 막대 오른쪽 끝의 **삽입 ＋** 버튼을 누르세요. 같은 메뉴가 열립니다.)

**③ 내용 쓰기**
그냥 쓰면 됩니다. 쓰는 즉시 오른쪽(또는 아래쪽)에 완성된 모양이 나타납니다.

**④ 표 넣기**
빈 줄에서 `/` → **표**. 칸에 내용을 채우세요. 표 위에 마우스를 올리면 칸을 늘리고 줄이는 버튼이 나타납니다.

**⑤ 저장하기**
- 쓰는 동안 **자동 저장**됩니다. 탭 줄 오른쪽 끝에 "자동 저장됨 14:32"처럼 표시됩니다.
- 이 자동 저장은 **그 컴퓨터의 그 브라우저 안**에만 남습니다. 다른 컴퓨터로 옮기거나 오래 보관하려면 위쪽 **저장** 버튼(또는 `Ctrl + S`)으로 **.md 파일**을 만들어 두세요.

## 4. 글쓰기 도우미

### 4-1. `/` 삽입 메뉴 (가장 중요한 기능)

**빈 줄에서 `/` 를 누르면** 넣을 수 있는 것들의 목록이 나타납니다.
각 항목에는 아이콘, 쉬운 이름, 한 줄 설명, 결과 예시가 함께 나와서 **무엇인지 보고 고를 수 있습니다.**

- 아래 화살표(↓)와 `Enter` 로 고르거나, 마우스로 클릭합니다.
- 계속 글자를 입력하면 걸러집니다. 한글 단어로 찾아도 됩니다. (예: `표`, `엑셀`, `할일`, `공식`, `순서도`, `웃음`)
- `Esc` 로 닫습니다.
- `/` 를 누르기 어렵다면 도구 막대 오른쪽의 **삽입 ＋** 버튼을 누르세요. 같은 메뉴가 열립니다.

| 분류 | 넣을 수 있는 것 |
| --- | --- |
| **글 모양** | 큰 제목, 중간 제목, 작은 제목, 점 목록, 번호 목록, 체크리스트(할 일), 인용문 |
| **넣기** | 표, 코드 상자, 수식(공식), 다이어그램(그림), 이모지 |
| **상자** | 참고 상자(파랑), 팁 상자(초록), 중요 상자(보라), 주의 상자(주황), 경고 상자(빨강) |
| **링크·기타** | 링크, 구분선, 템플릿으로 새 문서 만들기 |

굵게·기울임·취소선·코드 같은 글자 서식은 **위쪽 도구 막대**의 아이콘으로 합니다. 글자를 먼저 선택한 뒤 눌러 보세요.

### 4-2. 도구 막대

글 쓰는 곳 위쪽의 아이콘 줄입니다. 아이콘에 마우스를 올리면 한국어 설명이 나옵니다.
`↶ ↷` 실행 취소/다시 실행, `B` 굵게, `I` 기울임, `S` 취소선, `<>` 코드, 링크, `H1 H2 H3` 제목, 목록 3종, 인용, 표, 코드 블록, 수식, 다이어그램, 구분선, 상자, 서식 정리(✨), 삽입 ＋.

### 4-3. 체크리스트 (할 일 목록)

`/` → **체크리스트**, 또는 `- [ ] 할 일` 처럼 씁니다.
**미리보기에서 체크박스를 클릭하면** 체크되고, 목록 위에 **"체크리스트 3 / 6 완료 50%"** 진행 막대가 나타납니다. (들여쓴 하위 항목도 함께 셉니다.)

### 4-4. 표

- `/` → **표** 로 틀을 넣고 채웁니다.
- 엑셀·구글 시트에서 **표를 복사해서 붙여넣으면** 자동으로 표가 됩니다.
- **미리보기에서 표에 마우스를 올리면** 편집 버튼이 나타납니다.

| 버튼 | 하는 일 |
| --- | --- |
| 표 **아래쪽** 얇은 `＋` 띠 | 맨 끝에 행(줄) 추가 |
| 표 **오른쪽** 얇은 `＋` 띠 | 맨 끝에 열(칸) 추가 |
| 줄과 줄 사이, 칸과 칸 사이의 작은 `＋` | 그 자리에 끼워 넣기 |
| 줄 **왼쪽**의 `－` | 그 줄 삭제 |
| 칸 **위쪽**의 `－` | 그 열 삭제 |

- 칸의 글자는 **더블클릭**해서 고칠 수 있습니다.
- 잘못 눌렀다면 `Ctrl + Z` 한 번으로 되돌립니다.
- (표를 정리하고 싶다면 도구 막대의 **서식 정리**를 누르면 칸 너비가 가지런해집니다.)

### 4-5. 수식 (공식)

`/` → **수식(공식)** 을 누르면 수학·과학 공식 **42종**이 카드로 나옵니다.
미리보기를 보고 하나를 고르면 글 속에 들어갑니다. 대수, 미적분, 선형대수, 확률·통계, 물리·공학 등으로 나뉘어 있고 검색도 됩니다.

직접 쓸 수도 있습니다: 글 속에는 `$E=mc^2$`, 한 줄을 차지하게 하려면 `$$ … $$` 로 감쌉니다.

### 4-6. 다이어그램 (그림)

순서도, 시퀀스, 클래스, 상태, ER, 간트, 파이, 마인드맵 같은 그림을 **글자로 그립니다.**
`/` → **다이어그램(그림)** 에서 예시 **20종** 중 하나를 고르면 글 속에 들어가고, 미리보기에 그림으로 나타납니다.

- **그림 위에 마우스를 올리면** `PNG로 저장`, `SVG로 저장`, `편집` 버튼이 나옵니다.
  - **PNG로 저장**: 흰 배경의 고화질 그림 파일로 저장합니다. 문서·발표자료에 붙여 넣기 좋습니다.
  - **SVG로 저장**: 확대해도 깨지지 않는 그림 파일입니다.
- **그림을 더블클릭**하거나 `편집` 을 누르면 **마우스로 그리는 편집기**가 열립니다. 상자를 끌어서 옮기고, 선을 이어서 순서도를 만들 수 있습니다. 색도 바꿀 수 있습니다.
- 편집기에서 적용하면 글도 함께 바뀌고, `Ctrl + Z` 로 되돌릴 수 있습니다.

### 4-7. 이모지

- `:smile:`, `:rocket:`, `:tada:` 처럼 쓰면 😄 🚀 🎉 로 바뀝니다. 320여 종이 있습니다.
- 글 쓰는 곳에서 `:` 와 두 글자(예: `:sm`)를 입력하면 **후보 목록**이 나타납니다. `Enter` 로 고르세요.
- `/` → **이모지** 를 누르면 `:` 가 입력되며 후보가 나타납니다.

### 4-8. 색깔 상자 (콜아웃)

두 가지 방법이 있습니다.

1. `/` → **참고/팁/중요/주의/경고 상자**
2. 인용문 첫머리에 이모지를 넣기: `> 💡 알아 두면 좋은 내용` → 색깔 상자가 됩니다.
   지원 이모지: 💡 ⚠️ 🚨 🛑 ❗ ✅ ❌ ℹ️ 📌 🎯 🔥 📝

### 4-9. 이미지 넣기

- 캡처한 화면이나 복사한 그림을 글 쓰는 곳에 **붙여넣기(`Ctrl + V`)** 하면 글 속에 들어갑니다.
- 파일을 글 쓰는 곳으로 **끌어다 놓아도** 됩니다.
- 미리보기에서 그림을 **클릭하면 크게** 보입니다. `Esc` 로 닫습니다.
- 붙여넣은 그림은 브라우저에 저장되고 글에는 연결 정보만 남습니다. **글을 다른 곳에 가져갈 때는 [HTML로 내보내기](#7-내보내기와-인쇄)나 [전체 백업](#6-내-글-저장과-백업-중요)을 쓰세요.** (`.md` 파일에는 붙여넣은 그림 자체가 들어가지 않습니다.)

### 4-10. 템플릿

위쪽 **템플릿** 버튼을 누르면 **43종**의 서식이 나옵니다.

- **업무**: 회의록, 주간 보고, 일간 업무 보고, 인수인계서, 1:1 면담 기록, 견적서, 출장 보고서, 프로젝트 기획서, 프로세스 문서
- **개발**: 요구사항 명세, 장애 보고서, README, API 문서, 코드 리뷰 체크리스트, 변경 기록, 버그 리포트
- **개인**: 할 일, 일기, 독서 노트, 여행 계획, 가계부, 습관 추적, 버킷리스트
- **학습**: 학습 노트, 강의 노트(코넬식), 시험 대비 정리, 단어장, 논문 읽기 노트, 수학 공식 정리
- **기획·창작**: 블로그 글, 보도자료, 이력서, 자기소개서, 발표 대본
- **일정·관리**: 월간 계획, 프로젝트 일정표, 주간 식단표, 이사 체크리스트, 행사 준비 체크리스트
- **다이어그램**: 순서도, 시퀀스, 조직도, 마인드맵형 정리

카테고리를 누르거나 검색창에 단어를 입력해 찾고, 카드를 누르면 오른쪽에 미리보기가 나옵니다.
**"이 템플릿으로 새 문서"** 를 누르면 새 탭이 열립니다. `○○○` 로 표시된 곳을 채우면 되고, `{{날짜}}` 자리에는 오늘 날짜가 자동으로 들어갑니다. **지금 쓰던 글은 건드리지 않습니다.**

### 4-11. 서식 정리

도구 막대의 **서식 정리(✨)** 를 누르면 표 칸 너비 맞춤, 목록 기호 통일, 불필요한 공백·빈 줄 정리를 해 줍니다. 코드 상자와 수식 안의 내용은 건드리지 않습니다. 마음에 안 들면 `Ctrl + Z` 로 되돌립니다.

## 6. 내 글 저장과 백업 (중요)

MarkView는 글을 **서버로 보내지 않습니다.** 대신 두 가지 방법으로 보관합니다.

### 6-1. 자동 저장 (브라우저 안에)

- 쓰는 동안 0.5초 정도 뒤에 **자동으로 저장**됩니다.
- 탭 줄 오른쪽 끝에 상태가 나옵니다.

| 표시 | 뜻 |
| --- | --- |
| 저장 중… | 저장하는 중입니다 |
| 자동 저장됨 14:32 | 브라우저 안에 저장되었습니다 |
| 파일로 저장됨 | 내가 만든 .md 파일에도 저장되어 있습니다 |
| 저장 안 된 변경 있음 | 파일에는 아직 저장하지 않은 내용이 있습니다 (**저장** 버튼을 누르세요) |
| 저장 실패 — 다시 시도 | 누르면 다시 시도합니다. 계속 실패하면 바로 [전체 백업](#6-3-전체-백업-가장-안전한-방법)을 받으세요 |
| 이 컴퓨터에 저장되지 않는 임시 모드 | 브라우저가 저장을 막은 상태입니다. 닫으면 글이 사라지니 **저장** 으로 파일을 만드세요 |

> ⚠️ **자동 저장은 "그 컴퓨터, 그 브라우저" 안에만 있습니다.** 다음 경우에는 사라지거나 안 보입니다.
> - 브라우저의 **"인터넷 사용 기록 삭제" / "사이트 데이터·쿠키 삭제"** 를 실행했을 때
> - 다른 컴퓨터나 다른 브라우저로 열었을 때
> - USB를 다른 컴퓨터에 꽂아 쓸 때
> - 시크릿(InPrivate) 창에서 쓰다가 창을 닫았을 때

### 6-2. 파일로 저장 (.md 파일)

- 위쪽 **저장** (또는 `Ctrl + S`)
  - **Chrome·Edge**: 처음에는 저장할 위치를 묻고, 이후에는 **같은 파일에 덮어써서** 저장합니다.
  - **Firefox·Safari 등**: 누를 때마다 **다운로드 폴더에 새 파일**이 내려받아집니다.
- **저장 ▾ → 다른 이름으로 저장** 으로 위치·이름을 정할 수 있습니다.
- `.md` 파일은 메모장으로도 열리는 **일반 텍스트 파일**입니다. 프로그램이 사라져도 내용은 남습니다.

### 6-3. 전체 백업 (가장 안전한 방법)

**한 번에 모든 문서 + 붙여넣은 그림**을 파일 하나로 보관합니다.

1. 위쪽 **내보내기 ▾ → 전체 백업 내려받기**
2. `MarkView-백업-날짜-시간.json` 파일이 내려받아집니다.
3. 이 파일을 **USB·클라우드·다른 폴더**에 복사해 두세요.

**복원하기**

1. 위쪽 **열기 ▾ → 백업에서 복원…**
2. 백업 파일(.json)을 고릅니다.
3. "문서 N개, 이미지 M개를 불러옵니다" 확인 창에서 **복원하기**.

- 복원은 **지금 있는 글을 지우거나 덮어쓰지 않습니다.** 항상 **새 탭으로 추가**됩니다. 이름이 같으면 `(복원)` 이 붙습니다.
- 다른 컴퓨터로 글을 옮길 때도 이 방법이 가장 확실합니다.

> 💡 **추천 습관**: 중요한 글은 ① 끝낼 때 **저장**으로 .md 파일 만들기, ② 일주일에 한 번쯤 **전체 백업** 받기.

### 6-4. 저장 공간

브라우저의 저장 공간이 80% 이상 차면 알림이 나옵니다. 알림의 **백업 내려받기** 버튼을 누르고, 필요 없는 글을 정리하세요.
(붙여넣은 그림 중 7일 이상 어떤 글에서도 쓰이지 않은 것은 시작할 때 자동으로 정리됩니다.)

## 8. 여러 문서와 폴더 열기

### 8-1. 여러 탭

- **＋** 로 새 탭, 탭 이름 **더블클릭**으로 이름 바꾸기, **가운데 마우스 버튼**이나 `×` 로 닫기.
- 파일에 저장하지 않은 내용이 있는 탭을 닫으려 하면 확인 창이 뜹니다.
- 글 쓰는 위치와 스크롤 위치는 탭마다 기억합니다.

### 8-2. 파일 열기

**열기 ▾ → 파일 열기** 로 .md 파일을 엽니다. 파일을 **창 위로 끌어다 놓아도** 열립니다.

### 8-3. 폴더 열기

**열기 ▾ → 폴더 열기** 로 폴더를 고르면 왼쪽 **파일** 탭에 폴더 안의 문서 목록이 나타납니다.

- 파일을 누르면 새 탭으로 열립니다. 같은 파일을 또 눌러도 탭이 중복으로 생기지 않습니다.
- 문서 속의 **상대 경로 그림**(`![](images/a.png)`)과 **문서 간 링크**(`[다음 글](chapter2.md)`)가 폴더 기준으로 동작합니다. 링크를 누르면 그 문서가 열립니다.
- 폴더 구조가 있는 글(책, 노트, 블로그 원고)을 볼 때 편합니다.

| 브라우저 | 폴더 열기 |
| --- | --- |
| Chrome / Edge | ✅ 열기 + 저장도 폴더 안 파일에 **직접 덮어쓰기** |
| Firefox | ✅ 열기. 저장은 **다운로드로** 내려받습니다 (원본을 덮어쓰지 않아 안전합니다) |
| Brave | ✅ 열기(Firefox와 같은 방식). 기본 설정에서는 저장이 다운로드로 됩니다. 주소창에 `brave://flags/#file-system-access-api` 를 입력해 켜면 Chrome처럼 직접 저장됩니다. 앱에서 폴더 열기를 누르면 이 주소를 복사하는 버튼이 나옵니다 |

## 9. USB로 가지고 다니기

### 9-1. USB 파일 구성

```
MarkView-USB/
├─ MarkView.html     ← 이 파일을 더블클릭하면 실행됩니다 (인터넷·설치 필요 없음)
├─ 사용법.txt         ← 요약 안내
└─ 내 문서/           ← 내가 쓴 .md 파일을 저장해 두는 폴더
```

### 9-2. 사용 순서

1. `MarkView-USB` 폴더 전체를 USB에 복사합니다.
2. 어떤 컴퓨터에서든 USB를 꽂고 `MarkView.html` 을 **더블클릭**합니다. (Chrome·Edge 권장)
3. 글을 쓰고, 끝낼 때 **저장**으로 `내 문서` 폴더에 `.md` 파일을 만듭니다.
4. 다음에 다른 컴퓨터에서 이어서 쓰려면, **열기 ▾ → 폴더 열기**로 `내 문서` 폴더를 고르세요.

> ⚠️ **USB를 쓸 때 가장 중요한 점**: 자동 저장은 USB에 따라오지 않습니다. 다른 컴퓨터에서는 어제 쓴 글이 안 보이는 것이 정상입니다.
> **반드시 "저장"으로 .md 파일을 USB의 `내 문서` 에 만들어 두세요.**

### 9-3. USB 파일은 어디서 받나요?

- **[MarkView-USB.zip 내려받기](https://sh11025.github.io/MarkView/MarkView-USB.zip)** (약 4MB) → 압축을 풀면 `MarkView-USB` 폴더가 나옵니다. 이 폴더를 통째로 USB에 복사하세요.
- 이 파일은 웹사이트를 새로 올릴 때마다 **자동으로 최신 버전으로 다시 만들어집니다.** 항상 같은 주소에서 받으면 됩니다.
- 직접 만들려면 [16번](#16-개발자를-위한-안내)의 `npm run build:portable` 을 실행하세요. `release/MarkView-USB` 폴더가 만들어집니다.

### 9-4. USB에서 쓸 때 달라지는 점

- 앱 설치 버튼은 없습니다. (설치는 웹 주소로 열었을 때만 됩니다.)
- 맨 위에 "이 파일로 열면 글은 이 컴퓨터의 브라우저에 임시 저장됩니다" 안내가 나옵니다. 위 주의사항과 같은 내용이니, 닫아도 됩니다.
- 파일이 약 10MB로 큰 것은 수식·그림 엔진이 모두 들어 있기 때문입니다.

## 10. 인터넷 없이 쓰기와 앱으로 설치

### 10-1. 인터넷 없이 쓰기

- **웹 주소로 쓰는 경우**: 한 번이라도 열어 두었다면, 이후 인터넷이 끊겨도 같은 주소를 열면 됩니다. 수식, 다이어그램, 템플릿, PNG 저장 등 **모든 기능이 인터넷 없이 동작**합니다.
- **USB/파일로 쓰는 경우**: 처음부터 인터넷이 필요 없습니다.

### 10-2. 앱으로 설치하기

| 환경 | 방법 |
| --- | --- |
| **PC (Chrome, Edge)** | 웹 주소로 연 뒤 주소창 오른쪽의 **설치** 아이콘, 또는 화면 위쪽의 **설치** 버튼 |
| **안드로이드 Chrome** | 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가** |
| **아이폰 Safari** | 공유 버튼 → **홈 화면에 추가** |

설치하면 독립된 창으로 열리고, 바탕화면·시작 메뉴에서 바로 실행할 수 있습니다.

### 10-3. 새 버전이 나왔을 때

관리자가 새 버전을 올리면, 열려 있는 MarkView 화면 아래쪽에 **"새 버전이 있습니다. [새로고침]"** 이 나타납니다.

- **지금 쓰던 글은 사라지지 않습니다.** 자동으로 새로고침하지 않고, **직접 누를 때만** 바뀝니다.
- 쓰던 글을 정리한 뒤 **[새로고침]** 을 누르면 새 버전이 됩니다.
- 저장된 글은 업데이트해도 그대로 남습니다.

| **Safari** | 확인이 충분하지 않음 | 다운로드로 저장 | - | 사용은 가능할 수 있으나 점검하지 못했습니다 |
| **폰 브라우저** | ✅ 웹 주소로 | 다운로드로 저장 | - | 화면이 위아래 분할로 바뀝니다. 설치해서 쓰기를 권장합니다 |

> "같은 파일에 덮어쓰기"를 쓰는 브라우저는, 원본을 바꾸려 할 때 **브라우저가 먼저 허락을 물어봅니다.**
> 또한 **디스크의 파일이 밖에서 바뀌었는데 내가 쓰던 내용이 있으면, 내 글을 덮어쓰지 않고 알려 줍니다.**

## 14. 자주 묻는 질문과 문제 해결

**Q. 글이 사라졌어요!**
- 먼저 **같은 컴퓨터, 같은 브라우저**로 열었는지 확인하세요. (USB를 다른 컴퓨터에서 열면 자동 저장된 글은 안 보입니다.)
- **열기 ▾ → 백업에서 복원…** 으로 이전에 받아 둔 백업 파일(.json)이 있으면 복원하세요.
- 앞으로는 [6번](#6-내-글-저장과-백업-중요)처럼 **저장**과 **전체 백업**을 습관으로 하세요.

**Q. USB를 다른 컴퓨터에 꽂았더니 어제 쓴 글이 안 보여요.**
정상입니다. 자동 저장은 USB를 따라가지 않습니다. 저장해 둔 `.md` 파일을 **열기 ▾ → 폴더 열기** 로 `내 문서` 폴더를 열어서 불러오세요.

**Q. 하얀 화면이 되거나 오류 화면이 나와요.**
1. 화면의 **백업 내려받기** 를 먼저 누르세요. (글 보호가 가장 중요합니다.)
2. 브라우저 새로고침(`F5`)을 합니다.
3. 계속되면 ⚙ → **문제 정보 복사…** 를 눌러 내용을 복사해, 도와주는 사람에게 붙여 넣으세요.
   이 정보에는 **브라우저 종류·화면 크기·오류 메시지·문서 개수** 같은 기술 정보만 들어 있고, **내 글 내용·파일 이름·폴더 경로는 들어 있지 않습니다.**

**Q. 저장 상태에 "저장 실패" 또는 "임시 모드"가 나와요.**
브라우저가 저장 공간을 막은 상태입니다(시크릿 창, 저장 공간 부족, 브라우저 설정 등). 글을 쓰고 **저장** 으로 .md 파일을 만들어 두세요. 임시 모드에서도 **전체 백업**은 받을 수 있습니다.

**Q. 표 편집 버튼(＋, －)이 안 보여요.**
**미리보기 화면**에서 표 위에 마우스를 올려야 나타납니다. 폰에서는 표를 터치하세요. 인용문이나 목록 **안에 들어 있는 표**는 안전을 위해 미리보기 편집을 막아 두었으니, 글 쓰는 곳에서 직접 고치세요.

**Q. 수식이나 그림이 빨간 오류로 나와요.**
수식(`$…$`)이나 다이어그램의 문법이 틀린 것입니다. 오류 메시지의 줄 번호를 보고 고치거나, `/` 메뉴의 **수식(공식)·다이어그램(그림)** 예시를 골라서 고쳐 보세요. 노드 글자에 괄호가 들어간다면 큰따옴표로 감싸야 합니다. 예: `A["인증(JWT)"]`

**Q. Firefox에서 엑셀 표를 붙여넣어도 표로 안 바뀌어요.**
브라우저마다 붙여넣기 동작이 달라서 생길 수 있는 알려진 의심 항목입니다. 이럴 땐 `/` → **표**로 틀을 만들어 쓰거나 Chrome·Edge를 써 주세요.

**Q. 인쇄하면 배경이 어둡게 나올까요?**
아니요. 어두운 테마를 써도 인쇄·PDF는 **흰 종이에 검은 글자**로 나옵니다.

**Q. 내 글을 누가 볼 수 있나요?**
MarkView는 글을 어디로도 전송하지 않습니다. 광고·분석 도구도 없고 외부 글꼴·외부 서비스도 쓰지 않습니다. 모든 것이 내 컴퓨터 안의 브라우저 저장소에 있습니다. (공용 컴퓨터에서 쓴 뒤에는 글을 저장해 가져가고, 브라우저의 사이트 데이터를 삭제하세요.)

**Q. 모바일 폰에서 쓸 수 있나요?**
웹 주소로 열어 **홈 화면에 추가**하면 쓸 수 있습니다. 화면이 좁으면 편집/미리보기가 위아래로 나뉘고, 글 쓰는 곳 위의 **삽입 ＋** 버튼으로 같은 메뉴를 열 수 있습니다. 폰에서는 `.md` 파일 저장이 다운로드로 이루어집니다.

## 15. 인터넷에 올리기 (GitHub Pages)

> 이 부분은 **MarkView를 남들도 쓰게 올려 두는 관리자**를 위한 설명입니다. 쓰기만 하는 분은 건너뛰세요.
> GitHub Pages는 **무료**로 웹 주소를 만들어 줍니다. 단, 무료 계정에서는 저장소를 **공개(Public)** 로 해야 합니다. 이 저장소에는 글이 들어 있지 않고 프로그램 코드만 있으므로 공개해도 안전합니다. 내 글은 **각자의 브라우저 안**에만 있습니다.

이 저장소에는 **자동 배포 설정**(`.github/workflows/deploy.yml`)이 이미 들어 있습니다. 코드를 GitHub에 올리면(`main` 브랜치) **자동으로 시험하고 → 빌드하고 → 웹 주소를 만들어 줍니다.**

### 15-1. 처음 한 번: 저장소 만들고 올리기 (GitHub Desktop 사용)

명령어를 몰라도 되는 방법입니다.

1. [GitHub](https://github.com) 에 가입·로그인하고, [GitHub Desktop](https://desktop.github.com) 을 설치해 로그인합니다.
2. GitHub Desktop → **File → Add local repository…** 를 누르고, **이 프로젝트 폴더**(`markview` 폴더, `package.json` 이 들어 있는 폴더)를 고릅니다.
   - "이 폴더는 Git 저장소가 아닙니다"라는 안내가 나오면 **create a repository** 를 누릅니다.
   - 위쪽 상위 폴더가 아니라 **`markview` 폴더 자체**를 고르세요.
3. 이름 칸에 저장소 이름(예: `markview`)을 쓰고 **Create repository**.
   - `node_modules`, `dist`, `release` 같은 큰 폴더는 `.gitignore` 로 자동 제외되어 올라가지 않습니다.
4. **Commit to main** (처음이면 변경 목록을 모두 올리는 첫 저장입니다. 요약 칸에 `첫 업로드` 정도 쓰면 됩니다).
5. **Publish repository** 를 누릅니다. "Keep this code private" 의 **체크를 풀고(공개)** Publish.

### 15-2. GitHub Pages 켜기

1. 브라우저에서 올린 저장소 페이지(`https://github.com/사용자이름/저장소이름`)를 엽니다.
2. **Settings → Pages**
3. **Build and deployment → Source** 를 **GitHub Actions** 로 바꿉니다.
4. 위쪽 **Actions** 탭에서 `Deploy to GitHub Pages` 가 돌아가는 것을 확인합니다. 몇 분 뒤 초록색 ✔ 가 되면 성공입니다.
   - 처음에 실행되지 않았다면 Actions 탭 → 왼쪽 `Deploy to GitHub Pages` → **Run workflow**.
5. Settings → Pages 위쪽에 **웹 주소**가 나타납니다.
   ```
   https://사용자이름.github.io/저장소이름/
   ```
6. 이 주소를 Chrome·Edge로 열어 보세요. 주소 오른쪽에 **설치** 아이콘이 나오면 정상입니다.

> 이 앱은 **하위 경로**(`/저장소이름/`)에서도 정상 동작하도록 만들어져 있어서 따로 설정을 바꿀 필요가 없습니다.

### 15-3. 수정한 뒤 다시 올리기 (업데이트)

1. 파일을 고칩니다.
2. GitHub Desktop 에서 **Commit to main** → **Push origin**.
3. 자동으로 다시 시험·빌드·배포됩니다. (몇 분)
4. 이미 쓰고 있던 사람들 화면에는 **"새 버전이 있습니다. [새로고침]"** 이 나타납니다. 쓰던 글은 사라지지 않습니다.

### 15-4. USB용 파일은 자동으로 만들어집니다

따로 할 일이 없습니다. 코드를 올릴 때마다 자동 배포 과정이 **USB용 파일을 새로 만들어 웹사이트에 함께 올립니다.**

- 내려받는 주소: `https://사용자이름.github.io/저장소이름/MarkView-USB.zip`
  (이 저장소는 <https://sh11025.github.io/MarkView/MarkView-USB.zip>)
- 직접 만들고 싶다면 [16번](#16-개발자를-위한-안내)의 `npm run build:portable` 을 실행하면 `release/MarkView-USB` 폴더가 만들어집니다.

### 15-5. Netlify Drop (GitHub 대신, 더 간단한 방법)

가입 없이 폴더를 끌어다 놓기만 해도 웹 주소가 생깁니다.

1. `npm run build:web` 으로 `release/MarkView-Web` 폴더를 만듭니다.
2. <https://app.netlify.com/drop> 에 이 폴더를 끌어다 놓습니다.
3. 몇 초 뒤 주소가 나옵니다.

## 16. 개발자를 위한 안내

### 필요한 것

- [Node.js](https://nodejs.org) 22 이상 (LTS 권장)

### 명령어

```bash
npm install               # 처음 한 번: 필요한 부품 설치
npm run dev               # 개발용 실행 (브라우저에서 확인)
npm run typecheck         # 타입 검사
npm test                  # 단위 테스트
npm run test:e2e          # 브라우저 자동 점검 (Chromium)
npm run test:e2e:firefox  # 브라우저 자동 점검 (Firefox)
npm run build             # 웹 배포용 빌드 (dist/)
npm run build:web         # 웹 배포 패키지 (release/MarkView-Web)
npm run test:e2e:deploy   # 배포 점검 (하위 경로 + 오프라인)
npm run build:portable    # USB용 단일 HTML 만들기 (release/MarkView-USB)
npm run test:e2e:portable # USB용(file://) 자동 점검
```

변경한 뒤에는 `npm run typecheck && npm test` 가 통과해야 합니다.

### 기술 구성

React 19 · Vite · TypeScript · Tailwind CSS(앱 화면) · Zustand · IndexedDB(idb) · CodeMirror 6 · markdown-it · DOMPurify · KaTeX · highlight.js · Mermaid · vite-plugin-pwa · Vitest · Playwright

### 알려진 제약

- 폴더에 **직접 덮어쓰기 저장**은 Chrome·Edge(File System Access API)에서만 됩니다. 다른 브라우저는 다운로드로 저장합니다.
- 인용문·목록 안에 들어 있는 표는 미리보기에서 편집하지 않습니다(원문 접두어 처리 미구현, 의도적 비활성).
- Firefox에서 엑셀 표 붙여넣기 자동 변환 자동 시험은 브라우저 한계로 통과하지 못합니다(실사용에서는 직접 확인이 필요).
- 포터블(USB) 버전에는 서비스 워커·앱 설치가 없습니다.

### 구조와 작업 규칙

코드 구조, 지켜야 할 원칙(20개), 데이터 흐름은 [AGENTS.md](AGENTS.md)를 보세요.
